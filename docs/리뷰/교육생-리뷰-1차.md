# 굴착기 시뮬레이터 P0 교육생 리뷰 (1차)

먼저 밝혀둘 점 세 가지입니다.
- **읽은 범위:** `src/app/hud.ts`는 TEMPLATE 아래 표시 코드까지, `tools/trainee.ts`는 60행까지 읽었습니다(허용 범위를 조금 넘음). 금지된 폴더는 열지 않았습니다.
- **연습 도구의 한계:** 키를 뗀 뒤 약 0.3초 지난 상태만 보여줍니다. 그래서 "동시 조작 감속"은 항상 0%로 나와 확인하지 못했습니다.
- **눈 없이 조작:** 3D 화면 없이 글만 보고 했기 때문에, 일부 실패는 화면이 있었으면 피했을 수 있습니다.

## 1. 한 줄 총평

시동부터 첫 삽까지는 안내가 친절해서 금방 되지만, 흙이 버킷에 들어간 순간 안내가 사라져 "들기 → 선회 → 쏟기 → 돌아오기"는 전부 혼자 알아내야 합니다.

- **첫 사이클 성공:** 사이클을 노린 시도로 3번째(전체 실행으로 7번째). 12.6초, 0.30m³(50%), 흘림 0.
- **가득(100%) 담아 흘림 없이:** 8번째 시도. 11.5초, 0.60m³.
- **3사이클 연속:** 20번째 시도. 사이클 시간 11.5 → 15.3 → 16.0초, 덤프 0.60 → 0.50 → 0.45m³, 흘림 0 → 0 → 0.10m³. 시간도 흘림도 줄지 않았습니다.

## 3. 조작감

- **속도:** 붐 올리기 1초에 약 1.3~1.5m, 선회 최고 약 45°/초. 처음엔 빠르게 느껴졌지만 금방 익숙해집니다.
- **반응 지연:** 키를 누르면 0.3~0.4초에 걸쳐 레버가 기웁니다. `K 0.1` = +2cm, `K 0.2` = +10cm, `K 0.5` = +56cm, `K 1.0` = +1.48m. 짧게 톡톡 치면 미세 조작이 돼서 좋았습니다.
- **Shift:** 속도가 약 절반입니다(`Shift+K 0.5` = +25cm, `Shift+A 2.0` = 67° 대 `A 2.0` = 92°). 유용하지만 절반은 아직 빠릅니다. 선회 마무리에는 1/3~1/4 정도가 필요합니다.
- **동시 조작:** `K+A`, `S+J`, 4키 동시 모두 잘 됩니다. 4키 때 선회가 28° → 26°로 조금 느려지는 정도입니다. 반대 키 동시(`K+I`, `A+D`)는 상쇄되어 안 움직입니다.
- **선회 관성:** `A 2.0` 뒤 13° 더 밀리고, 급히 반대로 꺾으면(`A 2.0; D 0.5`) 6° 더 간 뒤 돌아옵니다. 납득됩니다. 흙을 담고 급반전을 반복하면(`...; K 1.0; A 1.5; D 1.5; A 1.5; D 1.5`) 0.09m³(15%) 흘립니다. 이건 좋은데 왜 흘렸는지 화면 설명이 없습니다.
- **굴착 저항:** 땅에 닿으면 붐이 멈추고(85%), 버킷을 땅에 박은 채 선회하면 거의 안 돕니다(`I 1.5; A 1.0` = -3°). 현실적이라 좋습니다.

이상하거나 비현실적으로 느껴진 것:
- 붐만 내리고 5초 있으면 버킷이 100% 찹니다(`I 5.0`). 누르기만 해도 흙이 담깁니다.
- `S 2.0`으로 0.4m 긁었는데 20% → 100%가 됩니다. 너무 쉽게 찹니다.
- 흙을 가득 담아도 선회 속도와 관성이 빈 버킷과 같습니다(둘 다 -79° → -92°).
- 주행 제자리 회전이 `Left 1.5`에 약 90°로 매우 빠릅니다. 장비 방향 표시가 없어 정확한 각도는 모릅니다.
- RPM 1에서도 선회는 21°(RPM 8은 28°)로 별 차이가 없습니다. 붐은 RPM 4에서 0.90m, 8에서 1.3m, 10에서 1.52m로 차이가 납니다.

## 4. 화면·문구

**어려운 말**
- "붐 / 암 / 버킷"이 각각 어느 부분인지 화면 어디에도 없습니다. 색칠한 그림 하나가 필요합니다.
- "패턴 ISO", "입력 키보드", "굴착 저항", "동시 조작 감속", "덤프", "사이클"에 설명이 없습니다.
- "RPM 8"은 회전수가 아니라 1~10 다이얼입니다. "엔진 다이얼 8/10"이 맞습니다.
- "굴착 저항 56%"가 좋은 건지 나쁜 건지 모릅니다(빨간 막대라 나쁜 것처럼 보임).
- `I`(위쪽 키)가 "붐 내리기"입니다. 실제 레버와 같다는 건 나중에 짐작했습니다. "레버를 앞으로 밀면 붐이 내려갑니다"라고 써 주세요.

**교육생에게 필요 없는 표시**
- 측정 패널의 "부피 보존 오차 0.000 %", "재생 검증 T", "화면 갱신 60 fps · 계산 60 Hz"는 개발자용입니다. `T` 키는 조작 방법 표에도 없습니다.

**부족한 표시**
- 버킷이 땅에 닿았는지, 얼마나 깊은지 알 방법이 없습니다. 연습 도구의 "지면에서"도 파인 바닥 기준이라 실제 깊이를 모릅니다(`I 1.0` 뒤 0.04m 아래로 나오지만 옆으로 옮겨 보니 약 0.25m 파여 있었음).
- 선회 각도, 버킷 각도(입구 방향), 암·붐이 끝까지 갔는지 표시가 없습니다.
- 들다가 노란 구역에 도로 떨어뜨린 흙은 어디에도 집계되지 않습니다(0.60 → 0.26m³인데 흘림 0.00).
- 주행 설명이 "↑↓←→"뿐이라 좌·우 막대와 어떻게 연결되는지 모릅니다.

**스크린샷 레이아웃**
- 외부 시점: 파란 구역이 왼쪽 아래 "조작 방법" 상자와 가운데 레버 패널 뒤에 반쯤 가려집니다. 덤프 후 화면에서 흙더미가 레버 패널 바로 위에 걸립니다.
- 운전석 시점: 레버 패널이 정면 아래(파는 자리)를 덮고, 검은 기둥이 좌우를 크게 가립니다. 버킷은 화면 맨 위에 바닥만 보입니다. 이 시점에서는 파는 곳이 안 보입니다.
- 시범 후 화면(4번째 장)에는 가운데 안내문이 아예 없습니다.
- 파란 컨테이너와 주황 콘이 무엇인지(장애물인지 장식인지) 설명이 없습니다.
- 글자가 12.5~13px라 1440 화면에서 작습니다. 특히 레버 라벨이 작습니다.

## 5. 배우는 데 도움이 된 것 (유지)

- 시동 → 안전레버 → 목표 순서로 한 번에 하나만 알려주는 안내. 시동 없이 조작하면 아무 일도 없고 "R 키를 눌러 시동을 거세요"가 그대로 떠 있어 바로 이해했습니다.
- 시동을 끄면 안전레버도 자동으로 잠기는 것.
- 레버 표시에 "암 펴기 W"처럼 동작 이름과 키가 같이 있고, 누르면 강조되는 것. 이것만 보고 첫 사이클을 했습니다.
- `P`로 패턴을 바꾸면 라벨도 같이 바뀌는 것.
- 노란·파란 구역과 범례 문구("여기를 판다 / 여기에 쏟는다").
- 적재량 %와 막대, 덤프/흘림 구분, 사이클 시간 표시.
- 선회 관성, 붐을 올리면 버킷이 기우는 것, 급반전 시 흘림. 실수하면 결과로 배우게 됩니다.
- `G` 시범 보기와 단계 문구("버킷을 오므려 흙을 가둔다").

## 6. 개선 요청 우선순위

**반드시 (교육이 안 됨)**
1. **단계별 안내 유지.** 지금은 흙이 0.01m³ 들어가면 안내가 사라집니다(`guide.ts` 22~25행). 상태에 따라 "암을 당기며 버킷을 오므리세요 → 버킷을 다 오므린 뒤 붐을 올리세요 → 왼쪽으로 선회 → 파란 구역 위에서 버킷을 펴세요 → 노란 구역으로 돌아가며 암을 펴세요"를 계속 띄워 주세요. 2~3사이클 뒤에는 끌 수 있게 해 주세요.
2. **실수 즉시 알림.** 저항 90% 이상으로 멈춤, 버킷이 덜 오므려진 채 들기, 구역 밖 쏟기, 급반전 흘림 때 가운데에 한 줄 이유를 띄워 주세요.
3. **부위 이름 그림.** 붐·암·버킷을 색으로 구분한 작은 그림을 레버 패널 옆에 두고, 누른 키에 해당하는 부위가 반짝이게 해 주세요.
4. **접지·깊이·낙하 지점 표시.** 버킷 날 끝 높이(원래 지면 기준 ±m)와 "땅에 닿음" 표시, 흙이 떨어질 위치의 바닥 표시.
5. **사이클 판정 기준 수정.** 노란 구역에서 판 흙이 파란 구역에 일정 비율 이상 들어가야 완료로 세어 주세요(근거는 7번).

**중요 (배우기 어려움)**
1. 선회 각도 표시와 파란 구역 정렬 표시(정면에 오면 색이 바뀌는 식).
2. 버킷 각도 표시(오므림 ↔ 펴짐)와 암·붐 끝 도달 표시.
3. 레버 패널과 조작 방법 상자가 구역을 가리지 않게 배치. 운전석 시점에서는 패널을 반투명하게 하거나 줄여 주세요.
4. 사이클 결과 요약: 완료할 때마다 "이번 14.3초 · 담은 양 100% · 흘림 0 · 도로 떨어뜨림 0.10" 표시.
5. 첫 사이클은 준비 자세에서 시작해 항상 최단이 됩니다(11.5 → 15.3 → 16.0초). 굴착 시작 ~ 다음 굴착 시작으로 재거나 첫 회는 최단 기록에서 빼 주세요.
6. Shift 미세 조작을 더 느리게(1/3~1/4) 하거나 단계를 고를 수 있게.

**있으면 좋음**
1. 개발자용 측정 3줄은 숨기고 별도 키로 열기.
2. "RPM" → "엔진 다이얼 n/10", "패턴 ISO" → "레버 방식: ISO(표준)" 같은 쉬운 말.
3. 시범(`G`)을 단계별로 멈추고 따라 하는 방식. 시범이 왜 RPM을 10으로 올리는지도 설명.
4. 컨테이너·콘의 의미 설명, 자기 장비(궤도·운전실) 근처 굴착 경고(2.3m 앞에서 100% 파져도 경고 없음).
5. 글자 크기 키우기, 주행 키 설명 추가.
6. 흙을 담았을 때 선회가 조금 무거워지는 느낌.

## 7. 이상 동작·버그 의심

실행은 모두 `cd "D:/projects/simulator/Forklane" && npx tsx tools/trainee.ts "<순서>"` 형식입니다.

1. **누르기만 해도 가득 참.** `R; F; I 5.0` → 날 끝 0.14m 아래, 앞뒤 이동 없이 적재 100%.
2. **뒤집힌 버킷에 흙이 담김.** `R; F; K 0.5; S 3.0; J 3.0; I 3.0; I 3.0` → 입구 "아래", 날 끝이 지면 0.29m 위인데 적재 82%.
3. **가만히 있어도 적재가 늘어남.** `R; F; I 1.5; A 1.0; wait 1.0` → wait 중 0.31 → 0.36m³.
4. **대부분 흘려도 사이클 완료.** `R; F; W 1.0; I 1.5; S+J 2.0; K+A 1.0; A 1.0; wait 0.7; L 3.0` → 덤프 0.25 / 흘림 0.35m³인데 완료 1회.
5. **파란 구역 흙을 파서 파란 구역에 쏟아도 완료.** `R; F; K 0.5; A 2.0; wait 1.0; W 1.0; I 2.0; S+J 2.0; K+J 0.5; J 1.0; K 1.0; L 3.0` → 덤프 0.60m³, 완료 1회. 구역 밖(오른쪽 35°)에서 판 흙도 같은 결과입니다(`R; F; K 0.5; D 1.0; wait 1.0; W 1.0; I 2.0; S+J 2.0; K+J 0.5; J 1.0; K 0.5; A 2.6; wait 1.0; L 3.0`).
6. **노란 구역에 도로 떨어진 흙 미집계.** `R; F; W 1.0; I 1.5; S 2.0; K 2.0` → 적재 0.60 → 0.26m³, 흘림 0.00.
7. **시범 기록이 내 기록에 섞이는 듯함.** 덤프 후 스크린샷과 운전석 스크린샷 모두 "완료한 사이클 1회 · 12.0 / 12.0초 · 덤프 0.54m³"입니다. 시범이 끝나면 초기화되는지 확인이 필요합니다(스크린샷만으로 본 추정).
8. **연습 도구 표기.** `...; D 2.0; wait 1.0` 뒤 선회가 "-0°"로 나옵니다. 사이클 0회일 때 "직전 사이클 0.0초"도 화면처럼 "—"가 맞습니다.
