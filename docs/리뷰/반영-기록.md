# 교육생 리뷰 반영 기록

P0 구현 뒤 "교육생 역할 에이전트가 써 보고 리뷰 → 개선"을 두 바퀴 돌렸다.
리뷰 원문: [1차](교육생-리뷰-1차.md), [2차](교육생-리뷰-2차.md)

교육생 에이전트는 화면 대신 `tools/trainee.ts`(실제 앱과 같은 키 입력 경로)와 스크린샷으로 조작했다.
사람 교육생이나 굴착기 운전 경험자의 평가는 아직 받지 않았다.

## 결과 요약

| 지표 | 처음 | 1차 반영 뒤 | 2차 반영 뒤 |
|---|---|---|---|
| 첫 사이클 성공까지 시도 | 3번째 (추측으로) | 1번째 (화면 안내만 따라서) | 1번째 (개발자가 같은 순서로 재확인) |
| 1차 지적 33개 | — | 해결 24, 일부 해결 7, 미해결 2 | 아래 "아직 남은 것" 참고 |
| 자동 테스트 | 30개 | 36개 | 39개 |

2차 반영분은 교육생 에이전트의 3차 확인을 받지 않았다. 2차 리뷰의 재현 명령을 개발자가 다시 돌려 확인했다.

## 1차 리뷰 → 반영

| 지적 | 반영 |
|---|---|
| 흙이 담기면 안내가 사라짐 | ①~⑦ 단계 안내가 사이클 내내 이어짐 (`src/app/guide.ts`, C 키로 끔) |
| 실수해도 이유를 모름 | 실수 순간 한 줄 알림 (`src/app/coach.ts`) |
| 붐·암·버킷이 어디인지 모름 | "자세" 패널: 부위별 색과 이름표가 붙은 옆모습 그림, 레버 글자도 같은 색 |
| 버킷 깊이·각도·선회 각도를 알 수 없음 | 날 끝 높이, 입구 방향, 선회 각도, 버킷 위치, 붐·암·버킷 진행률 막대, 위에서 본 그림 |
| 흙이 어디 떨어질지 모름 | 바닥에 낙하 지점 원 표시 (흰색·초록·빨강) |
| 누르기만 해도 버킷이 참 | 버킷 등으로 누르면 담기지 않고 거의 들어가지 않음 |
| 가만히 있어도 적재량이 늚 | 멈춘 버킷은 흙을 건드리지 않음 |
| 대부분 흘려도, 구역 밖 흙으로도 사이클 완료 | 굴착 구역의 흙 70% 이상, 쏟은 흙의 60% 이상이 덤프 구역, 굴착 구역으로 복귀해야 1회 |
| 도로 떨어뜨린 흙이 집계되지 않음 | "들다가 도로 떨어뜨림" 항목 추가 |
| 첫 사이클이 항상 최단 | 사이클 = 굴착 구역 출발 → 쏟기 → 굴착 구역 복귀 |
| 흙을 실어도 선회가 똑같음 | 실으면 가속·제동이 둔해짐. 엔진 다이얼이 선회 가속에도 영향 |
| 제자리 회전이 너무 빠름 | 주행 속도와 제자리 회전 속도를 낮춤 |
| Shift 미세 조작이 아직 빠름 | 1/4 속도로 |
| 패널이 구역을 가림, 글자가 작음 | 화면 배치를 새로 짜고 카메라 위치를 옮김. 글자 크기 키움 |
| 어려운 말, 개발자용 표시 | 쉬운 말로 바꿈. 개발자용 측정은 M 키로만. H 키 도움말에 부위·말뜻 설명 |
| 시범 기록이 내 기록에 섞임 | 시범은 처음 상태에서 시작하고, 끝나면 지형·기록을 되돌림 |

## 2차 리뷰 → 반영

| 지적 | 반영 |
|---|---|
| 흙을 남기고 돌아오면 알림 없이 안 세어짐 | 남긴 채 돌아와도 한 사이클로 마감하고 "버킷에 남김"을 알려 줌. ⑥ 안내는 버킷이 빌 때까지 유지 |
| 틀린 알림 3종 (오므리는 중 "들어 흙이 떨어짐", 가득 담았는데 "버킷을 펴라", 파는 중 "구역 밖에 쏟음") | 버킷이 땅 위에 있고 일부러 펴는 중이 아닐 때만 "덜 오므린 채"를 띄움. 가득 담았으면 "이제 붐을 올리세요". 파는 중 넘친 흙은 쏟은 것으로 보지 않음 |
| 진짜 실수 때 알림이 빠짐 | 같은 알림의 재표시 대기 시간을 줄임 |
| 붐이 땅에 너무 쉽게 깊이 박힘 | 붐으로 누르는 힘만으로는 약 0.3m까지만 들어감. ① 안내에 Shift 사용법 추가, 닿으면 "붐은 그만 내리고 암을 당기세요" |
| 뒤집힌 버킷에 흙이 담김 | 입구가 30° 넘게 아래를 향하면 담기지 않음 |
| ③ → ④ 전환이 이름 | 입구가 똑바로 위를 볼 때까지 ③ 유지 |
| 암이 접혀 구역에 못 미치면 "선회"만 반복 | 방향이 맞으면 "암을 펴서(당겨서) 버킷을 구역 위로" 안내 |
| ① 문장에서 키가 다음 낱말에 붙어 읽힘 | 키를 동작 바로 뒤 괄호에: "암을 펴서(W)" |
| 선회하다 스쳐 지나가도 복귀로 인정 | 선회가 거의 멈춘 상태로 굴착 구역에 있어야 복귀 |
| 같은 자리를 1m 넘게 팜 | 깊은 자리에서는 "옆자리를 파세요" 안내 |
| 구역 밖 굴착 경고가 늦음 | 구역 밖 흙을 담는 순간 알림 |
| 시범이 흙을 떨어뜨림 | 시범 동작 조정. 도로 떨어뜨림이 첫 사이클 0.21 → 0.06m³, 2·3번째 사이클 0 |
| 시범이 엔진 다이얼 10인 이유가 없음 | 시범 안내문에 설명 추가 |

## 아직 남은 것

- 시범을 단계별로 멈추고 따라 하는 방식
- 자기 장비(궤도·운전실) 가까이를 팔 때의 경고
- 화면: 위에서 본 그림이 작음, 운전석 시점에서 좌우 패널이 큼, 주행으로 돌린 차체 방향의 수치 표시 없음
- 붐만 내려도 날이 0.3m 들어가며 버킷의 약 1/4이 담긴다. 물리적으로는 그럴 수 있으나, 실제 장비와 비교한 조정이 필요하다
- 첫 사이클 시간은 첫 레버 입력부터 잰다
