# 굴착기(포크레인) 교육 시뮬레이터

직업훈련용 굴착기 조작 시뮬레이터. 전체 계획은 [docs/구현계획.md](docs/구현계획.md)에 있다.

**현재 단계: P0 핵심 검증** — 평지 연습장에서 키보드로 굴착 → 선회 → 덤프 한 사이클.
교육생 역할 에이전트의 리뷰를 세 차례 받아 반영했다: [docs/리뷰/반영-기록.md](docs/리뷰/반영-기록.md)

## 실행

```
npm install
npm run dev
```

브라우저에서 http://localhost:5173 을 연다.

| 명령 | 내용 |
|---|---|
| `npm run dev` | 개발 서버 실행 |
| `npm test` | 시뮬레이션 자동 테스트 |
| `npm run typecheck` | 타입 검사 |
| `npm run build` | 배포용 빌드 |
| `npx tsx tools/trainee.ts "R; F; K 1.0"` | 화면 없이 키 입력 순서를 시험 |

## 조작 (키보드)

| 키 | 기능 |
|---|---|
| R / F | 시동 / 안전레버 |
| W A S D | 좌 레버 (ISO: 암 펴기·당기기, 좌·우 선회) |
| I J K L | 우 레버 (ISO: 붐 내리기·올리기, 버킷 오므리기·펴기) |
| 방향키 | 주행 |
| Shift | 누르고 있는 동안 미세 조작 |
| + / − | 엔진 RPM |
| V | 운전석 / 외부 시점 (운전석에서는 조종 레버, 주행 레버·페달, 안전레버, 엔진 다이얼이 보이고 입력에 따라 움직인다) |
| P | 레버 패턴 (ISO / SAE) |
| G | 시범 운전 보기 (끝나면 지형과 기록을 처음으로 되돌림) |
| C | 단계별 안내 켜고 끄기 |
| X | 아래 레버 표시 접기 |
| H | 도움말 (부위 설명, 말뜻, 전체 키) |
| M | 개발자용 측정 표시 (부피 보존 오차, 재생 검증, 화면 갱신) |
| T | 재생 검증 (기록한 입력을 다시 돌려 같은 결과인지 확인) |
| Backspace | 처음부터 다시 |

## 구조

```
src/
  core/                 장비 공통 (다른 장비 시뮬레이터에서도 재사용)
    sim/                고정 주기(60Hz) 명령 형식, 수학
    terrain/            높이맵 지형, 토사 부피(팽창률, 안식각, 부피 보존)
    input/              키보드·조이스틱 → 가상 레버 → 명령, 레버 패턴
  equipment/excavator/  유압 실린더 운동 모델, 버킷-토사 상호작용, 시범 운전
  sites/                현장 정의 (P0: 평지 연습장)
  app/                  화면 (Babylon.js), 계기 표시
    guide.ts            "지금 할 일" 단계 안내 ①~⑦
    coach.ts            실수 순간 알림, 사이클 결과 요약
tests/                  자동 테스트
tools/trainee.ts        화면 없이 키 입력을 시험하는 연습 도구 (리뷰 에이전트도 이것을 쓴다)
```

시뮬레이션(`core`, `equipment`, `sites`)은 화면과 브라우저에 의존하지 않는다.
같은 명령을 같은 순서로 넣으면 항상 같은 결과가 나오므로, 입력 기록만으로 훈련을 재생하고 채점할 수 있다.

## P0에서 아직 하지 않은 것

- 조이스틱·페달: 입력 코드는 있으나 실제 장비로 검증하지 못했다.
- Tauri 설치판 패키징
- Havok 물리엔진 연결 (P0에는 부딪힐 물체가 없어 넣지 않았다. 장애물·덤프트럭이 나오는 단계에서 넣는다.)
- 굴착기 운전 경험자의 조작감 평가, 사람 교육생의 사용 평가, 저사양 PC 성능 측정
- 배포 파일 크기 줄이기 (지금은 Babylon.js 전체를 묶어 약 6MB)
- 실제 3D 모델과 소리 (지금은 단순한 도형)
- 장비 제원은 14톤급을 가정한 가상 값이다.
