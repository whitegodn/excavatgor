# 굴착기(포크레인) 교육 시뮬레이터

직업훈련용 굴착기 조작 시뮬레이터. 전체 계획은 [docs/구현계획.md](docs/구현계획.md)에 있다.

처음 화면에서 두 가지 모드 중 하나를 고른다.

| 모드 | 내용 |
|---|---|
| **시험 코스** | 굴착기운전기능사 실기 대비. 정해진 순서로 배우고 채점받는다. 레벨 0~3의 과제 12개가 동작한다. |
| **시뮬레이터 모드** | 여러 현장의 스테이지를 깨며 레벨을 올린다. 스테이지 7개가 동작한다. |

- 교육생 역할 에이전트의 리뷰 기록: [docs/리뷰/반영-기록.md](docs/리뷰/반영-기록.md)
- 시험과 관련된 수치(장애물 높이, 제한 시간, 사이클 수, 감점·실격 기준)는 **공식 규격 확인 전의 임시 값**이다. 화면에 "임시 규격"으로 표시한다.

## 시뮬레이터 모드

| 레벨 | 스테이지 | 현장 |
|---|---|---|
| 1 작업장 적응 | S1-1 깃발 따라 주행, S1-2 덤프트럭에 싣기 | 평지 주행 코스, 상차 작업장 |
| 2 현장 이동과 운반 | S2-1 오르막과 내리막, S2-2 흙 운반하기 | 언덕 코스, 운반 현장 |
| 3 도로와 본 작업 | S3-1 도로 타임 어택, S3-2 덤프트럭 가득 싣기, S3-3 통과 구역 지나 쏟기 | 도로 코스, 상차 작업장, 시험장 |

- **레벨업:** 경험치는 스테이지별 최고 점수의 합이다(불합격한 점수도 들어간다). 140 / 320 / 560이 되면 레벨 2(조수) / 3(기사) / 4(반장)가 되고, 그 레벨의 스테이지가 열린다. 점수에 따라 별 1~3개를 받는다. 최고 레벨 뒤의 목표는 별 21개를 모두 모으는 것이다.
- **덤프트럭:** 적재함 벽(1.9m)보다 높은 데서 쏟아야 실린다. 트럭은 단단해서, 버킷이 적재함 벽보다 낮은 채로 트럭 쪽으로 가면 벽에 막히고 접촉으로 센다(한 번 닿아서 뗄 때까지 1회, 3회면 실격). 안내는 오른쪽 과제 표시의 "버킷 높이"가 3.5m가 된 뒤에 선회하라고 한다.
- **주행:** Q 키로 고속 단을 켠다. 레버를 놓으면 금방 멈춘다. 오르막에서는 느려지고 내리막에서는 조금 빨라지며, 비탈을 비스듬히 타면 아래쪽으로 미끄러진다. 버킷을 땅에 끌거나 도로 코스에서 아스팔트를 벗어나면 감점이다.
- **운반:** 가야 할 구역의 거리와 방향이 화면에 나온다. 흙을 가득 실은 채 고속 단으로 급하게 꺾으면 흘린다.
- 벨트 없이 장비를 움직이면 그 자리에서 실격으로 끝난다(시험 코스도 같다).
- 기록은 시험 코스와 따로 저장한다.

- **배경:** 현장마다 배경이 다르다. 공사 현장(가설 울타리, 현장 사무실, 자재, 안내판, 작업자, 멀리 타워크레인), 도로와 도심(아스팔트 길과 차선, 상가와 건물, 가로등, 가로수, 세워 둔 차), 언덕(흙길, 나무, 덤불, 바위). `src/app/view/scenery.ts`에서 만든다.

아직 없는 것: 배경과의 충돌(건물·차·울타리를 그냥 통과한다. 덤프트럭은 버킷만 막는다), 좁은 문·후진·주차 과제, 레벨 4 전용 스테이지, 움직이는 차량과 사람, 경사에서의 굴착(차체 기울기는 화면에만 반영되고 계산에는 들어가지 않는다), 타이어식 굴착기. 배경은 단순한 상자 모양이다.

## 소리와 그래픽

장비와 건물, 소리는 코드로 만들고, 하늘·땅·도로의 질감과 소품 몇 가지는 사진으로 만든 무료 자료(Poly Haven, CC0)를 쓴다.

- **소리** (`src/app/audio.ts`): 브라우저의 소리 합성으로 만든다. 엔진음은 엔진 다이얼과 부하에 따라 높낮이와 크기가 변한다. 유압, 선회, 궤도, 굴착, 흙 쏟기, 실린더가 끝에 닿는 소리, 경음기, 후진 경고음, 알림음이 장비의 실제 움직임에 맞춰 난다. 브라우저 규칙상 키나 마우스를 한 번 누른 뒤부터 소리가 난다.
- **그래픽** (`src/app/view/atmosphere.ts`): 먼 곳의 안개, 색 보정, 부드러운 그림자, 배기 연기와 굴착·주행 먼지. 품질 "높음"에서는 빛 번짐, 구석 음영, 선명도 보정이 더해진다. 저사양 PC는 "낮음"을 쓴다.
- **사진 자료** (`src/app/view/assets.ts`, 파일은 `public/assets/polyhaven/`, 약 26MB): 하늘 사진(하늘과 주변 빛), 흙·아스팔트·골함석·녹 질감, 소품 모델(가로등, 바위, 콘크리트 방호벽, 드럼통). 사진 속 해의 방향을 그림자 방향과 맞췄다. 소품 모델은 삼각형이 많아(하나에 3만~6만 개) 현장마다 몇 개만 놓는다. 파일을 읽지 못하면 코드로 그린 하늘과 소품이 대신 나온다.
- 장비에는 궤도 바퀴, 배기관, 경광등, 작업등, 거울, 난간을 더했다. 그래도 장비와 건물의 모양은 상자와 원통이다. 굴착기와 덤프트럭의 실제 3D 모델은 아직 없다.

## 과정 구성 (① 자격증 취득 과정)

| 레벨 | 내용 | 과제 |
|---|---|---|
| 0 입문 | 부위·말뜻 퀴즈, 시동부터 종료까지 12단계 절차 | L0-1, L0-2 |
| 1 기초 조작 | 붐, 암, 버킷, 선회를 하나씩 (공중의 목표 지점에 날 끝 대기) | L1-1 ~ L1-4 |
| 2 복합 조작 | 여러 레버를 함께 써서 목표 지점으로, 제한 시간 | L2-1, L2-2 |
| 3 굴착 작업 연습 | 한 사이클 → 연속 3사이클 → 버킷 통과 구역 높이 연습 → 통과 구역 지나 4사이클(시험 방식, 임시 규격) | L3-1 ~ L3-4 |
| 4 코스 운전 연습 | 준비 중 | — |
| 5 모의 실기시험 | 준비 중 | — |

- **버킷 통과 구역:** 실기시험의 굴착작업에서는 굴착 지점과 쏟는 지점 사이에 기둥(폴) 두 개가 서 있고, 버킷은 그 사이의 통과 구역으로만 지나가야 한다. 아래에는 줄이, 위에는 가상의 통과 제한선이 있어 건드리면 실격이다. 여기서는 아래 줄 1.3m, 위쪽 제한선 4.0m로 두었다(공식 도면의 수치를 확인하지 못한 임시 값). L3-3에서 높이 맞추기만 연습하고, L3-4와 S3-3에서 흙을 옮기며 지나간다. 자유 연습에서는 O 키로 세우고 치운다.
- **파인 깊이 표시:** 땅은 깊을수록 어둡게 칠하고 25cm마다 등고선 같은 띠를 넣는다. 버킷 아래 땅이 5cm 넘게 파였으면 3D 화면의 그 자리에 "깊이 0.24m"를 적고, 왼쪽 단면 그림에는 0.5m 간격의 눈금과 그 단면에서 가장 깊은 곳의 깊이를 표시한다.
- 앞 과제를 합격(100점 만점에 60점, 레벨 0은 100점)해야 다음 과제가 열린다.
- 기록은 브라우저 안에만 저장한다. 계정과 서버, 수료증은 P2에서 만든다.
- 레벨 0~2를 모두 통과하면 브론즈 등급 "입문 운전자"가 된다.

## 실행

```
npm install
npm run dev
```

브라우저에서 http://localhost:5173 을 연다.

| 명령 | 내용 |
|---|---|
| `npm run dev` | 개발 서버 실행 |
| `npm test` | 시뮬레이션 자동 테스트 |
| `npm run typecheck` | 타입 검사 |
| `npm run build` | 배포용 빌드 |
| `npx tsx tools/trainee.ts "B; R; F; K 1.0"` | 화면 없이 키 입력 순서를 시험 (자유 연습) |
| `npx tsx tools/trainee.ts --task L1-1 "B; R; F; K 0.5"` | 과제를 화면 없이 해 보고 채점표 보기 (`--list`: 과제 목록) |

| 키 | 기능 |

| B / Space | 안전벨트 / 경음기 |
| R / F | 시동 / 안전레버 |
| W A S D | 좌 레버 (ISO: 암 펴기·당기기, 좌·우 선회) |
| I J K L | 우 레버 (ISO: 붐 내리기·올리기, 버킷 오므리기·펴기) |

| T | 재생 검증 (기록한 입력을 다시 돌려 같은 결과인지 확인) |
| Backspace | 처음부터 다시 |
| Esc | 일시 정지 (계속 / 다시 / 메뉴) |

## 구조

```
src/
  core/                 장비 공통 (다른 장비 시뮬레이터에서도 재사용)
    sim/                고정 주기(60Hz) 명령 형식, 수학
    terrain/            높이맵 지형, 토사 부피(팽창률, 안식각, 부피 보존)
    input/              키보드·조이스틱 → 가상 레버 → 명령, 레버 패턴
  equipment/excavator/  유압 실린더 운동 모델, 버킷-토사 상호작용, 시범 운전
    scoring/            채점표 (항목별 점수, 합격선, 실격)
  sites/                현장 정의 (평지 연습장)
  curriculum/           과정: 과제 정의, 과제 심판, 진도·해금
    excavatorLicense.ts ① 자격증 과정의 레벨과 과제 (임시 수치 포함)
    objectives/         과제 종류별 심판: 절차, 목표 지점, 굴착 사이클
    progress.ts         과제 기록, 해금, 등급
  app/                  화면 (Babylon.js), 계기 표시
    screens.ts          과정 메뉴, 과제 설명, 퀴즈, 일시 정지, 결과
    guide.ts            굴착 "지금 할 일" 단계 안내 ①~⑦
    coach.ts            실수 순간 알림, 사이클 결과 요약
tests/                  자동 테스트
tools/trainee.ts        화면 없이 키 입력을 시험하는 연습 도구 (리뷰 에이전트도 이것을 쓴다)
```

시뮬레이션(`core`, `equipment`, `sites`)은 화면과 브라우저에 의존하지 않는다.
같은 명령을 같은 순서로 넣으면 항상 같은 결과가 나오므로, 입력 기록만으로 훈련을 재생하고 채점할 수 있다.

## P1에서 아직 하지 않은 것

- 레벨 4 코스 운전, 레벨 5 모의 실기시험
- 시험 규격 확인: 큐넷 공개문제의 코스 치수, 시간, 채점 항목. 실기의 코스 운전은 타이어식 굴착기(핸들·가속 페달)로 보는 것으로 알고 있으나 확인하지 못했다. 맞다면 레벨 4에는 타이어식 주행 모델이 따로 필요하다.
- 메뉴 화면은 React 없이 만들었다 (계획서는 React + Vite). 화면이 더 늘어나면 다시 판단한다.
- 필기 모의고사, 계정·서버·수료증 (P2)

## P0에서 아직 하지 않은 것

- 조이스틱·페달: 입력 코드는 있으나 실제 장비로 검증하지 못했다.
- Tauri 설치판 패키징
- Havok 물리엔진 연결 (P0에는 부딪힐 물체가 없어 넣지 않았다. 장애물·덤프트럭이 나오는 단계에서 넣는다.)
- 굴착기 운전 경험자의 조작감 평가, 사람 교육생의 사용 평가, 저사양 PC 성능 측정
- 배포 파일 크기 줄이기 (지금은 Babylon.js 전체를 묶어 약 6MB)
- 굴착기·덤프트럭·건물의 실제 3D 모델, 녹음한 장비 소리 (지금은 단순한 도형과 합성한 소리)
- 장비 제원은 14톤급을 가정한 가상 값이다.
