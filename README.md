# 굴착기(포크레인) 교육 시뮬레이터

직업훈련용 굴착기 조작 시뮬레이터. 전체 계획은 [docs/구현계획.md](docs/구현계획.md)에 있다.

처음 화면에서 두 가지 모드 중 하나를 고른다.

| 모드 | 내용 |
|---|---|
| **시험 코스** | 굴착기운전기능사 실기 대비. 정해진 순서로 배우고 채점받는다. 레벨 0~3의 과제 11개가 동작한다. |
| **시뮬레이터 모드** | 여러 현장의 스테이지를 깨며 레벨을 올린다. 스테이지 6개가 동작한다. |

- 교육생 역할 에이전트의 리뷰 기록: [docs/리뷰/반영-기록.md](docs/리뷰/반영-기록.md)
- 시험과 관련된 수치(장애물 높이, 제한 시간, 사이클 수, 감점·실격 기준)는 **공식 규격 확인 전의 임시 값**이다. 화면에 "임시 규격"으로 표시한다.

## 시뮬레이터 모드

| 레벨 | 스테이지 | 현장 |
|---|---|---|
| 1 작업장 적응 | S1-1 덤프트럭에 싣기, S1-2 깃발 따라 주행 | 상차 작업장, 평지 주행 코스 |
| 2 현장 이동과 운반 | S2-1 오르막과 내리막, S2-2 흙 운반하기 | 언덕 코스, 운반 현장 |
| 3 도로와 본 작업 | S3-1 도로 타임 어택, S3-2 덤프트럭 가득 싣기 | 도로 코스, 상차 작업장 |

- **레벨업:** 경험치는 스테이지별 최고 점수의 합이다. 140 / 320 / 520이 되면 레벨 2(조수) / 3(기사) / 4(반장)가 되고, 그 레벨의 스테이지가 열린다. 점수에 따라 별 1~3개를 받는다.
- **덤프트럭:** 적재함 벽(1.9m)보다 높은 데서 쏟아야 실린다. 낮게 넣으면 트럭에 부딪힌 것으로 센다.
- **주행:** Q 키로 고속 단을 켠다. 오르막에서는 느려지고 내리막에서는 조금 빨라진다. 버킷을 땅에 끌면 감점이다.
- 기록은 시험 코스와 따로 저장한다.

아직 없는 것: 실제 도로와 건물 같은 배경, 다른 차량, 장애물과의 충돌, 경사에서의 굴착(차체 기울기는 화면에만 반영되고 계산에는 들어가지 않는다), 타이어식 굴착기.

## 과정 구성 (① 자격증 취득 과정)

| 레벨 | 내용 | 과제 |
|---|---|---|
| 0 입문 | 부위·말뜻 퀴즈, 시동부터 종료까지 12단계 절차 | L0-1, L0-2 |
| 1 기초 조작 | 붐, 암, 버킷, 선회를 하나씩 (공중의 목표 지점에 날 끝 대기) | L1-1 ~ L1-4 |
| 2 복합 조작 | 여러 레버를 함께 써서 목표 지점으로, 제한 시간 | L2-1, L2-2 |
| 3 굴착 작업 연습 | 한 사이클 → 연속 3사이클 → 장애물 넘겨 4사이클(시험 방식, 임시 규격) | L3-1 ~ L3-3 |
| 4 코스 운전 연습 | 준비 중 | — |
| 5 모의 실기시험 | 준비 중 | — |

- 앞 과제를 합격(100점 만점에 60점, 레벨 0은 100점)해야 다음 과제가 열린다.
- 기록은 브라우저 안에만 저장한다. 계정과 서버, 수료증은 P2에서 만든다.
- 레벨 0~2를 모두 통과하면 브론즈 등급 "입문 운전자"가 된다.

## 실행

```
npm install
npm run dev
```

브라우저에서 http://localhost:5173 을 연다.

| 명령 | 내용 |
|---|---|
| `npm run dev` | 개발 서버 실행 |
| `npm test` | 시뮬레이션 자동 테스트 |
| `npm run typecheck` | 타입 검사 |
| `npm run build` | 배포용 빌드 |
| `npx tsx tools/trainee.ts "B; R; F; K 1.0"` | 화면 없이 키 입력 순서를 시험 (자유 연습) |
| `npx tsx tools/trainee.ts --task L1-1 "B; R; F; K 0.5"` | 과제를 화면 없이 해 보고 채점표 보기 (`--list`: 과제 목록) |

## 조작 (키보드)

| 키 | 기능 |
|---|---|
| B / Space | 안전벨트 / 경음기 |
| R / F | 시동 / 안전레버 |
| W A S D | 좌 레버 (ISO: 암 펴기·당기기, 좌·우 선회) |
| I J K L | 우 레버 (ISO: 붐 내리기·올리기, 버킷 오므리기·펴기) |
| 방향키 | 주행 |
| Shift | 누르고 있는 동안 미세 조작 |
| + / − | 엔진 RPM |
| V | 운전석 / 외부 시점 (운전석에서는 조종 레버, 주행 레버·페달, 안전레버, 엔진 다이얼이 보이고 입력에 따라 움직인다) |
| P | 레버 패턴 (ISO / SAE) |
| G | 시범 운전 보기 (끝나면 지형과 기록을 처음으로 되돌림) |
| C | 단계별 안내 켜고 끄기 |
| X | 아래 레버 표시 접기 |
| H | 도움말 (부위 설명, 말뜻, 전체 키) |
| M | 개발자용 측정 표시 (부피 보존 오차, 재생 검증, 화면 갱신) |
| T | 재생 검증 (기록한 입력을 다시 돌려 같은 결과인지 확인) |
| Backspace | 처음부터 다시 |
| Esc | 일시 정지 (계속 / 다시 / 메뉴) |
| Enter | 메뉴·결과 화면의 기본 단추 |

## 구조

```
src/
  core/                 장비 공통 (다른 장비 시뮬레이터에서도 재사용)
    sim/                고정 주기(60Hz) 명령 형식, 수학
    terrain/            높이맵 지형, 토사 부피(팽창률, 안식각, 부피 보존)
    input/              키보드·조이스틱 → 가상 레버 → 명령, 레버 패턴
  equipment/excavator/  유압 실린더 운동 모델, 버킷-토사 상호작용, 시범 운전
    scoring/            채점표 (항목별 점수, 합격선, 실격)
  sites/                현장 정의 (평지 연습장)
  curriculum/           과정: 과제 정의, 과제 심판, 진도·해금
    excavatorLicense.ts ① 자격증 과정의 레벨과 과제 (임시 수치 포함)
    objectives/         과제 종류별 심판: 절차, 목표 지점, 굴착 사이클
    progress.ts         과제 기록, 해금, 등급
  app/                  화면 (Babylon.js), 계기 표시
    screens.ts          과정 메뉴, 과제 설명, 퀴즈, 일시 정지, 결과
    guide.ts            굴착 "지금 할 일" 단계 안내 ①~⑦
    coach.ts            실수 순간 알림, 사이클 결과 요약
tests/                  자동 테스트
tools/trainee.ts        화면 없이 키 입력을 시험하는 연습 도구 (리뷰 에이전트도 이것을 쓴다)
```

시뮬레이션(`core`, `equipment`, `sites`)은 화면과 브라우저에 의존하지 않는다.
같은 명령을 같은 순서로 넣으면 항상 같은 결과가 나오므로, 입력 기록만으로 훈련을 재생하고 채점할 수 있다.

## P1에서 아직 하지 않은 것

- 레벨 4 코스 운전, 레벨 5 모의 실기시험
- 시험 규격 확인: 큐넷 공개문제의 코스 치수, 시간, 채점 항목. 실기의 코스 운전은 타이어식 굴착기(핸들·가속 페달)로 보는 것으로 알고 있으나 확인하지 못했다. 맞다면 레벨 4에는 타이어식 주행 모델이 따로 필요하다.
- 메뉴 화면은 React 없이 만들었다 (계획서는 React + Vite). 화면이 더 늘어나면 다시 판단한다.
- 필기 모의고사, 계정·서버·수료증 (P2)

## P0에서 아직 하지 않은 것

- 조이스틱·페달: 입력 코드는 있으나 실제 장비로 검증하지 못했다.
- Tauri 설치판 패키징
- Havok 물리엔진 연결 (P0에는 부딪힐 물체가 없어 넣지 않았다. 장애물·덤프트럭이 나오는 단계에서 넣는다.)
- 굴착기 운전 경험자의 조작감 평가, 사람 교육생의 사용 평가, 저사양 PC 성능 측정
- 배포 파일 크기 줄이기 (지금은 Babylon.js 전체를 묶어 약 6MB)
- 실제 3D 모델과 소리 (지금은 단순한 도형)
- 장비 제원은 14톤급을 가정한 가상 값이다.
